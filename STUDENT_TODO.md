# Student checklist

Complete tasks in order. The minimum is a bot with `/start`, `/help`, `/quiz`, `/score`, `/reset`, five questions per quiz, inline answers, per-user progress, duplicate protection, tests, Docker run, and a working Render webhook.

- [ ] [01 Create a Telegram bot](tasks/01-create-telegram-bot.md)
- [ ] [02 Handle basic commands](tasks/02-command-handling.md)
- [ ] [03 Implement quiz logic](tasks/03-quiz-logic.md)
- [ ] [04 Add inline buttons](tasks/04-inline-buttons.md)
- [ ] [05 Manage user sessions](tasks/05-user-sessions.md)
- [ ] [06 Write tests](tasks/06-testing.md)
- [ ] [07 Run Docker locally](tasks/07-docker.md)
- [ ] [08 Deploy to Render](tasks/08-deployment.md)
- [ ] Complete [submission/REPORT.md](submission/REPORT_TEMPLATE.md) and remove any secrets before pushing.

Optional after the minimum: categories, randomized questions, difficulty levels, a leaderboard, or persistent scores. These are not required and may need extra design or a database.
